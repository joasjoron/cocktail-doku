# Cocktail-doku 🍸

Jeu de révision inspiré de Métrodoku, basé sur les 36 cocktails du **Socle des Cocktails de Référence 2025**
(Ministère de l'Éducation nationale, APEB, Association des Barmen de France).

## Règles

- Remplissez les 9 sous-verres avec un cocktail qui respecte le critère de sa ligne **et** celui de sa colonne.
- Un cocktail ne peut être utilisé qu'une fois par grille. Une bonne réponse est définitive.
- Trois erreurs maximum.
- « Grille du jour » : la même grille pour tout le monde chaque jour, avec suivi de la série de victoires.
- « Nouvelle grille » : grilles d'entraînement illimitées.

## Mise en ligne

Le site est une page HTML unique (`index.html`), sans compilation.
Il est publié avec GitHub Pages : Settings → Pages → Deploy from a branch → `main` / `(root)`.
